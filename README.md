# RockPaperScissors_by_tsvdon
This is an extended version of the "Rock Paper Scissors" game, to be played in the console by a person and the computer:

- Winning gives the winner 1 point. A draw gives no points.
- The game is played in sessions. A session starts when the person begins playing and ends when the person chooses to end playing.
- There is a score for each session.
- At the end of each round the person chooses to play another round or to quit, which will end the session.
- If the person chooses to play another round, they are given the option to use an unfair advantage against the computer in the next round.

How the unfair advantage works:

- In a normal scenario the person and the computer each have a 1 in 3 chance to win.
- If the person chooses to use the unfair advantage, the chance that the computer should win is reduced to 1 in 5.
